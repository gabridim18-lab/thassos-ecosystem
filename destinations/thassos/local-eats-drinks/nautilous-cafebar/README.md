# Nautilous Cafebar — Local Eats & Drinks V1

Locația în baza Thassos: `destinations/thassos/local-eats-drinks/nautilous-cafebar/`.

- `cafe-bar.json` — profil complet, plajă prin `beachSlug: skala-sotiros`, coordonate, contact, facilități, descrieri și SEO în 6 limbi, imagini și storyboard.
- `menu.json` — meniu documentar transcris din 3 fotografii, cu prețuri istorice neconfirmate.
- `imagini_manifest.json` — cele 10 nume exacte; încarcă `.webp` local, în `images/`.
- `previzualizare.html` — pagina demo self-contained: HTML, CSS și JS incluse intern; se deschide local prin dublu click.

## Mod de utilizare
1. Descarcă și dezarhivează ZIP-ul.
2. Copiază cele 10 fotografii WebP din folderul tău local în `images/` fără redenumiri.
3. Deschide `previzualizare.html` în browser.
4. După confirmarea numelui și a meniului, poți folosi datele pentru website-ul public / ecosistem.

Datele externe și recenziile sunt informații furnizate de utilizator, nu reprezintă certificări oficiale. Nu folosi fotografiile Google Maps comercial fără drepturi de utilizare.
