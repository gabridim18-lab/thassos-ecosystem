# Before publishing

- [ ] Verify business's preferred display name and the phone with the owner.
- [ ] Upload all 10 WebP images with original exact base filenames; check case/diacritics.
- [ ] Confirm permission to publish all photographs.
- [ ] Check current opening days/hours, especially outside the tourist season.
- [ ] Request official current menu if menu prices or dishes will be shown.
- [ ] Check if reservations are accepted and choose the approved contact flow.
- [ ] Confirm whether delivery/takeaway, wheelchair access, parking and pets are current.
- [ ] Verify whether your area catalog has a Skala Kallirachis record; do not assume a beach slug.
- [ ] Check for an existing restaurant with the same identity before importing.
- [ ] After the images are uploaded, set active flags only in the appropriate records.
