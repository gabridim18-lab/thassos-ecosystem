# Pinch of Salt — Skala Prinos, Thassos

Acest pachet conține fișiere pentru import în ecosistemul Thassos, în directorul:

`destinations/thassos/restaurants/pinch-of-salt/`

## Conținut

- `restaurant.json` — descrieri în RO / EN / EL / DE / BG / SR, date de contact, program furnizat, facilități, coordonate, galerie.
- `menu.json` — 16 elemente din cele patru capturi de meniu; **fără prețuri** și **fără an confirmat**.
- `imagini_manifest.json` — 11 fotografii WebP și 4 capturi originale ale meniului.
- `catalog-entry.json` — înregistrare de import pentru catalogul central (nu modifică indexul automat).
- `previzualizare.html` — prezentare locală; se poate deschide direct în browser.
- `DE_CONFIRMAT.md` — aspectele rămase de verificat.

## Import

1. Copiază folderul `pinch-of-salt` în `destinations/thassos/restaurants/` din repository.
2. Verifică dacă indexul central al proiectului acceptă schema `catalog-entry.json` (este compatibilă cu structura exemplului Oasis, dar nu verificată cu repository-ul live).
3. Adaugă în index numai după verificarea datelor și drepturilor de publicare.
4. Nu afișa prețuri pentru felurile de mâncare: nu au fost furnizate.
