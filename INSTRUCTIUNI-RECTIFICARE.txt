INSTALARE CU GITHUB DESKTOP (Windows)
1) In GitHub Desktop deschide repository-ul thassos-ecosystem.
2) Foloseste Fetch origin si Pull origin (daca apar modificari noi).
3) Extrage toate FISIERELE din ZIP direct in RADACINA folderului
   local thassos-ecosystem si accepta Replace/Overwrite pentru cele
   doua fisiere existente. ATENTIE: nu copia un folder suplimentar
   'thassos_fix_temp' peste repository; pastreaza structura din ZIP.
4) In GitHub Desktop vei vedea doua fisiere modificate (si acest
   document, daca l-ai copiat). Foloseste Commit to main si Push origin.
5) In GitHub -> Actions urmareste:
   - Validate beach JSON -> SUCCESS (verde)
   - Build Thassos social catalog -> SUCCESS (verde)
   Generatorul ar trebui apoi sa creeze catalog/thassos-catalog.json
   si sa-l trimita automat in repository.
6) Dupa generare, in GitHub Desktop foloseste din nou Fetch origin si
   Pull origin ca sa preiei fisierul nou de catalog creat de workflow.

PORNIRE STUDIO LOCAL
Din folderul local thassos-ecosystem deschide terminal si ruleaza:
    py -m http.server 8000
Apoi deschide in browser:
    http://localhost:8000/studio/
Nu deschide studio/index.html direct din Windows Explorer cu file://.

trimite mesajul exact al erorii (noua eroare poate fi diferita).
